# Node alpha.4 / Python a3 — prepared pre-alpha release

Prepared November 2, 2026. Candidate packages are Node `agindow@0.1.0-alpha.4`
and Python `agindow==0.1.0a3`. Registry installation applies after publication;
the latest published pair remains alpha.3/a2.

## Changes and upgrade

Both SDKs extend reviewed selective repair to concrete nested and array parent
pointers, finite string maps, exact empty-string/null semantics and bounded exact
unit/epoch scaling. Independent facts, explicit scoped rules and host verification
remain required. Ambiguous paths and unsupported changes are refused atomically.

Node `compareOperation` and Python `compare_operation` expose explicit advisory
operation-contract comparison. Declared schemas report directional compatibility;
observed data cannot establish requiredness, and coverage gaps stay explicit.
Comparisons do not load guard policy or enable repair.

The docs selector and web changelog distinguish this prepared pair from the
three retained published editions. Existing detection windows and opt-in repair
configuration remain required. Run the configured detection controls and your
reviewed repair fixtures before upgrading. Source patch export remains local;
validation and draft publication require separately authorized hosts.

## Publication checklist

- Run the full [source gate](../BUILD.md) and cross-language parity checks.
- Build npm tarball and Python wheel/sdist; confirm metadata, installability,
  legal notices and identical packaged WASM bytes. Record SHA-256 checksums.
- Review the allowlisted public export independently before source publication.
- Publish each new version once, then sync the registry-confirmed docs matrix
  and capture the immutable paired docs snapshot before deploying the website.

No upload, tag, push or deployment is part of preparation. Local checks do not
qualify production traffic, hosted identity or hosted PR delivery.
