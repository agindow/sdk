# Node alpha.4 / Python a3 — pre-alpha release

Published November 2, 2026. Node `agindow@0.1.0-alpha.4` and Python
`agindow==0.1.0a3` are available on npm and PyPI. Both registries match the
reviewed release archive integrity values.

## Changes and upgrade

Both SDKs extend reviewed selective repair to concrete nested and array parent
pointers, finite string maps, exact empty-string/null semantics and bounded exact
unit/epoch scaling. Independent facts, explicit scoped rules and host verification
remain required. Ambiguous paths and unsupported changes are refused atomically.

Node `compareOperation` and Python `compare_operation` expose explicit advisory
operation-contract comparison. Declared schemas report directional compatibility;
observed data cannot establish requiredness, and coverage gaps stay explicit.
Comparisons do not load guard policy or enable repair.

The docs selector and web changelog distinguish this published pair from the
three retained published editions. Existing detection windows and opt-in repair
configuration remain required. Run the configured detection controls and your
reviewed repair fixtures before upgrading. Source patch export remains local;
validation and draft publication require separately authorized hosts.

## Distribution and verification

The npm tarball, Python wheel and sdist contain identical release WASM bytes.
Isolated npm ESM/CJS and Python wheel installs pass runtime readiness, original
result identity and operation-comparison checks. The standalone public source
build, lint, runtime tests and Node/Python parity gate passed independently.
See [BUILD.md](../BUILD.md) for the reproducible source gate.

The allowlisted public export omits private customer-host composition and keeps
the required public capability catalog tracked. The original registry archives
retain the README bytes from preparation; current source READMEs reflect
confirmed publication. Existing package versions are never rebuilt or republished.

Local checks do not qualify production traffic, hosted identity or hosted PR
delivery. Website deployment remains a separate operation.
