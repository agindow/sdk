This pre-alpha release pairs **Node `agindow@0.1.0-alpha.2`** with **Python `agindow==0.1.0a1`**. Both are published and use the same Rust/WASM guest. This tag covers both packages.

## What changed

- The statistical guest is the default. Supply scoped baseline/current evidence windows to detect drift; an unconfigured installation produces no findings.
- Both SDKs now offer opt-in selective repair for reviewed, tool/side-scoped top-level field renames. Node uses `selectiveRepair`; Python uses `selective_repair`. Repairs use shared Rust span patches and require independent synchronous verification. Repair is off by default; configure reviewed rules and `repair` or `strict` mode explicitly.
- SDK READMEs include independently runnable detection controls, configuration guidance, readiness and bypass behavior, audit boundaries and write-safety guidance.
- The public repository includes the in-path Rust runtime, WASM bindings, Node/Python SDKs, host adapters, public contracts and their tests under Apache-2.0.

## Install or upgrade

Requires Node **22+** or Python **3.11+**.

```sh
npm install agindow@0.1.0-alpha.2
```

```sh
python -m pip install --upgrade agindow==0.1.0a1
```

Keep vendor credentials in your application and retain explicit detector selections. Node `sdk.ready` remains a settling Promise; Python readiness remains a boolean. Run the changed, unchanged, unconfigured and insufficient-window controls in the [quickstart](https://agindow.com/docs/quickstart). See [SDK configuration](https://agindow.com/docs/sdk/configuration) before enabling selective repair.

## Behavior and limits

Observe mode retains original results and never applies repairs. Generic callables default to reads: explicitly mark writes or unknown operations. Infrastructure failures bypass inspection and preserve the upstream outcome. A policy refusal is different from an engine failure, and a response-phase refusal cannot undo a completed upstream write.

Reviewed selective repair covers top-level field renames with independent verification. It does not infer business intent, convert units, or authorize arbitrary payload rewrites. Statistical findings remain independent of repair verification.

These are pre-alpha packages. Installing or upgrading does not activate detection, enable repair, or establish production protection. This release does not qualify managed execution, durable replay, or production traffic behavior.
