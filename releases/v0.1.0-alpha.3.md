# Node alpha.3 / Python a2 — pre-alpha release

Published October 29, 2026 on npm and PyPI. This pair contains Node
`agindow@0.1.0-alpha.3` and Python `agindow==0.1.0a2`.

## Changes

- Node CLI: explicit local source binding, deterministic reviewed rename patch
  export and source-fix export, with consent, digest and stale-source checks.
- Node raw request repair preserves the original string, Buffer or Uint8Array
  representation after verified application.
- Python: existing runtime API with the rebuilt shared guest.
- Redesigned first-call Quickstart, Node/Python integration and verified repair
  workflows, dedicated method references and audited command/configuration guides.
- Matching current documentation, install examples and publication status.

The CLI exports patches for review; it does not apply them automatically.
Validation and draft publication require separate authorized hosts. No managed
source-fix backend is included. Configured detection windows and opt-in repair
requirements remain unchanged; this is a pre-alpha release.

## Distribution and verification

Install Node `agindow@0.1.0-alpha.3` or Python `agindow==0.1.0a2`.
Both registries confirm this pair. GitHub release assets are the original
registry archives with verified registry integrity and SHA-256 checksums;
packages are not rebuilt or republished under an existing version.

The public source is produced by the reviewed allowlisted exporter, retaining
separate Git history and excluding private backends, credentials and deployment
operations. See [BUILD.md](../BUILD.md) for independent build and test commands.
Repository and standalone export checks cover the actual SDK/guest, detection
controls, independent repair verification, examples and cross-language parity.

The current source READMEs record confirmed publication. Immutable registry
archives retain the README bytes captured when they were packaged.

This is a prerelease for evaluation. It does not qualify live vendor behavior,
production protection, hosted identity or automated PR delivery.
